Lösungen¶

1)

$\int_{y=0}^{1-x} (2xy - x^2 - y^2) \mathrm{d}y = \left[xy^2 - x^2y - \dfrac{y^3}{3}\right]_0^{1-x} = x(1-x)^2 - x^2(1-x) - \dfrac{(1-x)^3}{3} = 2x - 4x^2 - \dfrac{1}{3} + \dfrac{7x^3}{3}$

$\int_{x=0}^{1} \left(2x - 4x^2 - \dfrac{1}{3} + \dfrac{7x^3}{3}\right) \mathrm{d}x = \left[x^2 - \dfrac{4x^3}{3} - \dfrac{x}{3} + \dfrac{7x^4}{12} \right]_0^1 =-\dfrac{1}{12}$

2)

Wir integrieren über den Bereich, in dem x zwischen 0 und 1 liegt und y zwischen den Geraden y = 0 und y = x. Dies beschreibt ein Dreieck. Man kann den Bereich auch so beschreiben, dass y zwischen 0 und 1 liegt und x zwischen der Geraden x = y und x = 1: $\int_{x=0}^{1} \int_{y=0}^{x} (x^2 + y^2) \mathrm{d}y\mathrm{d}x = \int_{y=0}^{1} \int_{x=y}^{1} (x^2 + y^2) \mathrm{d}x\mathrm{d}y$

2a) $\int_{x=0}^{1} \int_{y=0}^{x} (x^2 + y^2) \mathrm{d}y\mathrm{d}x =\int_{x=0}^{1} \left[x^2y + \frac{y^3}{3}\right]_0^x \mathrm{d}x =\int_{x=0}^{1} \frac43 x^3 \mathrm{d}x = \left[ \frac{x^4}{3} \right]_0^1 = \frac13$

2b) $\int_{y=0}^{1} \int_{x=y}^{1} (x^2 + y^2) \mathrm{d}x\mathrm{d}y =\int_{y=0}^{1} \left[ \frac13x^3+y^2x \right]_y^1 \mathrm{d}y =\int_{y=0}^{1} (\frac13+y^2-\frac13y^3-y^3 )\mathrm{d}y$
$\;\;\;\;\;=\left[\frac13y+\frac13y^3-\frac13y^4 \right]_0^1 = \frac13$

Schnittpunkte: $-x(x-3) = -2x, \; x_1 = 0, \; -x+3 = -2 \rightarrow x_2 = 5, \; y_1 = 0, \; y_2 = -10$

Integral: $\int_{x=0}^{5} \int_{y=-2x}^{-x(x-3)} \mathrm{d}y\mathrm{d}x = \dfrac{125}{6}$

Flächenschwerpunkt:

$x_s = \dfrac{1}{A}\iint_{(A)} x \mathrm{d}A = \dfrac{6}{125}\int_{x=0}^{5} \int_{y=-2x}^{-x(x-3)} x \mathrm{d}y\mathrm{d}x = \dfrac{5}{2}$

$y_s = \dfrac{1}{A}\iint_{(A)} y \mathrm{d}A = \dfrac{6}{125}\int_{x=0}^{5} \int_{y=-2x}^{-x(x-3)} y \mathrm{d}y\mathrm{d}x = -\dfrac{5}{2}$
