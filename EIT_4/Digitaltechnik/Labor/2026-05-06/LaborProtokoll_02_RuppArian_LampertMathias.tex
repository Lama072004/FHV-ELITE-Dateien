\section{Introduction}
% ─────────────────────────────────────────────────────────────────────────────

Sequential circuits, unlike purely combinational circuits, possess memory: their
output depends not only on the current inputs but also on the history of previous
inputs stored in flip-flops. They are the basis of all digital systems that store
state, count events, or synchronise operations to a clock signal.

This laboratory exercise investigates three fundamental sequential building blocks:
the \textbf{shift register}, the \textbf{monoflop}, and the \textbf{synchronous
counter}. A shift register stores a sequence of bits and moves them one position on
each rising clock edge. A monoflop (one-shot) generates a pulse of defined duration
in response to a trigger event. A synchronous BCD counter increments its binary
output by one on each rising clock edge, resetting to zero after reaching nine.

All three components are combined in a progressive design task: first a chaser
(moving) light is implemented, then extended with a catch function, and finally
augmented with a catch counter displayed in BCD code.

The objectives of this laboratory are:
\begin{itemize}[leftmargin=1.5em]
  \item To understand the operating principle of shift registers, monoflops, and
        synchronous counters.
  \item To design, simulate in LTSpice, and assemble three sequential circuits on
        a breadboard.
  \item To implement a power-on reset circuit ensuring a defined initial state after
        power-up.
  \item To debounce a push-button using a D-type flip-flop and gate logic.
  \item To combine multiple ICs into a functional system and verify correct
        end-to-end behaviour on the breadboard.
\end{itemize}

The theoretical background was reviewed according to~\cite{Floyd2006}
and~\cite{TietzeSchenk1999}.

\section{Theoretical Background}
% ─────────────────────────────────────────────────────────────────────────────

\subsection{Shift Register (74HC164)}

A shift register is a chain of D-type flip-flops sharing a common clock line.
On each rising clock edge, the data bit present at the serial input is loaded into
the first flip-flop, while every subsequent flip-flop takes over the value of its
predecessor.
The 74HC164 is an 8-bit serial-in/parallel-out shift register.
Its data input is the AND combination of pins A and B; tying one permanently high
makes the other the effective serial data input.
An active-low asynchronous clear ($\overline{\text{CLR}}$) resets all flip-flops to
zero immediately, regardless of the clock.

\subsection{D-type Flip-Flop (74HC74)}

The 74HC74 contains two independent positive-edge-triggered D-type flip-flops, each
with active-low asynchronous preset ($\overline{\text{PR}}$) and clear
($\overline{\text{CLR}}$) inputs.
On a rising clock edge, output $Q$ takes the value present at input $D$.
The asynchronous inputs override the clock: $\overline{\text{PR}}$ low forces
$Q = 1$; $\overline{\text{CLR}}$ low forces $Q = 0$, independently of the clock
or $D$.

\subsection{Power-On Reset}

After power-up, flip-flops settle in undefined states.
A power-on reset (POR) circuit generates a short active reset pulse immediately
after $V_{CC}$ rises.
An RC circuit ($R = \SI{1}{\mega\ohm}$, $C = \SI{1}{\micro\farad}$) charges slowly
after power-on; the capacitor voltage is fed into a Schmitt-trigger inverter
(74HC132).
While $V_C$ is below the Schmitt upper threshold $U_S$, the inverter output remains
high (reset active, all flip-flops cleared).
Once $V_C$ exceeds $U_S$, the inverter output falls low (reset released).
The switch-on delay is:
\[
  t_e = \tau = R \cdot C = \SI{1}{\mega\ohm} \times \SI{1}{\micro\farad}
  = \SI{1}{\second}
\]
This is long enough to allow the supply voltage to settle fully before the reset
is released.

\subsection{Monoflop (74HC221)}

The 74HC221 is a dual retriggerable monoflop with active-low clear.
It generates a precisely timed output pulse whose width is set by an external
resistor $R_{ext}$ and capacitor $C_{ext}$:
\begin{equation}
  t_W = 0.7 \cdot R_{ext} \cdot C_{ext}
  \label{eq:monoflop}
\end{equation}
The monoflop is triggered by a rising edge at input B (with A low).
During the pulse, $\overline{Q}$ is low (blocking the shift register clock);
after the pulse, $\overline{Q}$ returns high (clock released).

\subsection{BCD Decade Counter (74HC160)}

The 74HC160 is a synchronous 4-bit decade counter that counts from 0 to 9 in
natural binary (BCD), resetting to 0 on the next clock edge after 9.
It features an active-low asynchronous clear ($\overline{\text{CLR}}$), a
synchronous parallel load ($\overline{\text{LOAD}}$), and two count-enable inputs
(ENP, ENT).
The ripple-carry output (RCO) goes high at count~9 and can be used to cascade
multiple counter stages.

\subsection{Task 3.1 -- Chaser Light (8-bit Shift Register)}
% ════════════════════════════════════════════════════════════════════

\textbf{Component values used:}
$R_{POR} = \SI{1}{\mega\ohm}$,\quad
$C_{POR} = \SI{1}{\micro\farad}$,\quad
$V_{CC} = \SI{5}{\volt}$,\quad
clock: \SI{1}{\hertz}.

\subsubsection{Circuit Description and Design}

The chaser light circuit uses the 74HC164 8-bit shift register as its core.
One LED is connected via a current-limiting resistor to each of the eight parallel
outputs (QA--QH).
A single logic ``1'' is injected at startup and then shifted one position per clock
cycle, illuminating exactly one LED at a time.

To inject exactly one ``1'' at startup and never again, the first flip-flop of the
74HC74 is configured as follows:
the $\overline{\text{CLR}}$ input receives the active-low POR signal, the D input
is tied permanently to $V_{CC}$, and the clock input receives the same clock as
the shift register.
While the POR is active ($\overline{\text{CLR}}$ low), $Q_{FF1}$ is held at zero.
At the first rising clock edge after POR releases, $Q_{FF1}$ goes high for exactly
one clock period (since D~= high), providing a single ``1'' to the shift register
data input.
Before the second rising edge, $Q_{FF1}$ has returned low.
This ensures that only one ``1'' is ever present in the shift register chain at
any time.

To make the light wrap around after LED8, the serial output QH of the 74HC164 is
fed back to the serial data input (pins A and B tied together).

The power-on reset RC circuit ($R = \SI{1}{\mega\ohm}$, $C = \SI{1}{\micro\farad}$,
switch-on delay $t_e \approx \SI{1}{\second}$) drives a 74HC132 Schmitt-trigger
inverter whose output provides the active-low $\overline{\text{CLR}}$ signal to
both the 74HC74 and the 74HC164.

\subsection{Task 3.2 -- Catch Circuit (Monoflop Extension)}
% ════════════════════════════════════════════════════════════════════

\textbf{Additional components:}
$R_{mono} = \SI{2}{\mega\ohm}$,\quad
$C_{mono} = \SI{1}{\micro\farad}$,\quad
$R_{pull} = \SI{10}{\kilo\ohm}$.

\subsubsection{Circuit Description and Design}

Task~3.2 extends the chaser light with a catch function: whenever LED5 is ON and
the push-button is pressed, the moving light freezes at LED5 for approximately
\SI{2}{\second}, after which it continues normally.

Three sub-circuits are added to the existing design.

\paragraph{Button Debounce and Catch Detection (74HC74, second flip-flop).}
The push-button is debounced and its effect gated by LED5 using the second D-type
flip-flop of the 74HC74.
The $\overline{\text{PR}}$ input is tied to $V_{CC}$.
The $\overline{\text{CLR}}$ input is connected to the output of the LED5 shift
register stage (Q5 of the 74HC164): when LED5 is OFF (Q5 low, hence
$\overline{\text{CLR}}$ low), $Q_{FF2}$ is held at zero and no trigger can occur.
The D input is tied to $V_{CC}$, and the clock input is connected to the
push-button via a \SI{10}{\kilo\ohm} pull-down resistor to GND.
Only when LED5 is ON (Q5 high, $\overline{\text{CLR}}$ high) can the flip-flop
respond: on the first rising edge from the button, $Q_{FF2}$ goes high and
triggers the monoflop.
This simultaneously debounces the button (only the first edge counts) and ensures
the catch is only active when LED5 is lit.

\paragraph{Monoflop (74HC221) -- Catch Timer.}
The 74HC221 monoflop generates the hold pulse.
With $R_{ext} = \SI{2}{\mega\ohm}$ and $C_{ext} = \SI{1}{\micro\farad}$, the
calculated hold time is:
\begin{equation}
  t_{W,\text{calc}} = 0.7 \times \SI{2}{\mega\ohm} \times \SI{1}{\micro\farad}
  = \SI{1.4}{\second}
  \label{eq:monoflop_calc}
\end{equation}
\[
  \boxed{t_{W,\text{calc}} = \SI{1.4}{\second}}
\]
The monoflop is triggered by the rising edge of $Q_{FF2}$ at input~B (with A tied
low, $\overline{\text{CLR}}$ connected to the POR signal).
During the pulse, $\overline{Q}_{mono}$ is low.

\paragraph{Clock Blocking (74HC00 NAND Gate).}
A NAND gate from the 74HC00 blocks the clock signal to the 74HC164 during the
monoflop pulse.
One input of the NAND gate receives the waveform generator clock (via the 74HC132
Schmitt buffer); the other input receives $\overline{Q}_{mono}$ of the monoflop
inverted (i.e.\ a second NAND gate used as an inverter, or directly $Q_{mono}$
depending on the gate polarity chosen).
While $\overline{Q}_{mono}$ is low, the NAND output is permanently high: no rising
edges reach the shift register, and the light dot stays fixed at LED5 for the
duration of the monoflop pulse.

\subsection{Task 3.3 -- Catch Counter (BCD Counter Extension)}
% ════════════════════════════════════════════════════════════════════

\textbf{Additional components:} 74HC160 decade counter, 4 LEDs with
current-limiting resistors.

\subsubsection{Circuit Description and Design}

Task~3.3 extends the catch circuit by counting the number of successful catches and
displaying the count in BCD code on 4~additional LEDs.
The 74HC160 synchronous decade counter is used for this purpose.

Each time the light is caught, the monoflop generates a pulse.
The rising edge of $Q_{mono}$ (i.e.\ the end of the hold pulse, when the clock is
released again) increments the counter by one.
The four BCD outputs QA--QD of the 74HC160 drive 4~LEDs directly, displaying the
count from 0 to 9 in binary.

The counter connections are:
\begin{itemize}[leftmargin=1.5em]
  \item $\overline{\text{CLR}}$: connected to the POR signal (resets counter to 0
        at power-on).
  \item ENP, ENT: both tied to $V_{CC}$ (counting always enabled).
  \item $\overline{\text{LOAD}}$: tied to $V_{CC}$ (parallel load disabled).
  \item CLK: connected to $Q_{mono}$ (rising edge on each successful catch).
  \item QA--QD: connected to 4~LEDs via current-limiting resistors.
\end{itemize}

After 9~catches, the counter automatically resets to 0 on the next catch due to
the decade counter's built-in modulo-10 behaviour.

\subsubsection{LTSpice Simulation}

\begin{figure}[H]

increments correctly on each monoflop rising edge. The BCD output was verified
to advance from 0000 to 1001 (0--9) before wrapping back to 0000.
