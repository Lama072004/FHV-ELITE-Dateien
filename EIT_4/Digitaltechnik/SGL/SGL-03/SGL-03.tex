\section{Internal Structure of Simple PLDs (GAL)}
Simple Programmable Logic Devices (SPLDs), specifically the \textbf{GAL (Generic Array Logic)}, are organized into specific logic planes[cite: 104, 110]:

\begin{itemize}
    \item \textbf{AND-Plane (Programmable):} Inputs are connected to a grid where connections are programmed to create product terms.
    \item \textbf{OR-Plane (Fixed):} These terms are fed into an OR-gate to produce the final logic sum.
    \item \textbf{OLMC (Output Logic Macrocell):} Contains flip-flops to allow sequential logic like state machines[cite: 66, 104].
\end{itemize}

\section{Difference between Simple and Complex PLD (CPLD)}
The difference lies in the scale and the way components are connected:
\begin{itemize}
    \item \textbf{Integration}: A CPLD consists of multiple SPLD-like function blocks on a single chip.
    \item \textbf{Interconnect}: CPLDs use a central \textbf{Programmable Interconnect Matrix (PIM)} to link these blocks, whereas SPLDs are self-contained[cite: 61, 67].
\end{itemize}

\section{Structure of Field-Programmable Gate Arrays (FPGA)}
FPGAs use a distributed "Sea of Gates" architecture[cite: 122]:
\begin{itemize}
    \item \textbf{Configurable Logic Blocks (CLB):} Arranged in a grid, these contain Look-Up Tables (LUT) and Flip-Flops[cite: 60, 66].
    \item \textbf{Programmable Routing:} A grid of wires and switches allows connections between any CLBs[cite: 67].
\end{itemize}
